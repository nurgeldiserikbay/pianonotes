## 🔍 Как проверить

### Проверка скорости на разных экранах:
1. Откройте игру в окне браузера
2. Измените размер окна (большое/маленькое)
3. Запустите игру - скорость должна быть одинаковой относительно размера экрана
4. Проверьте при повороте экрана на мобильном устройстве

### Проверка фаз сложности:
1. Запустите игру
2. Наблюдайте за увеличением скорости по мере игры
3. Скорость должна плавно увеличиваться (не скачками)
4. К 50 очкам/30 секундам - переход на фазу 2
5. К 150 очкам/60 секундам - переход на фазу 3

### Проверка perfect/combo:
1. Попробуйте точно попасть по ноте (когда она близко к линии)
2. При perfect должна появляться анимация scale
3. При комбо x2 и выше должен появляться текст "COMBO xN!"
4. При комбо x5 должен сработать slow motion (0.25s)
5. Очки должны начисляться с множителем за комбо

### Проверка near-miss:
1. Установите рекорд (например, 100 очков)
2. Играйте до проигрыша, набрав 98-99 очков
3. На экране game over должно появиться сообщение "Было близко! Ещё 1 до рекорда"

### Проверка daily challenge:
1. Откройте консоль браузера (F12)
2. Проверьте localStorage: `localStorage.getItem('pianoNotes_dailyChallenge')`
3. Играйте и достигните цели (20 perfect, 500 очков или комбо x10)
4. Проверьте, что прогресс сохраняется

### Проверка анимаций:
1. Spawn: новые ноты должны появляться с анимацией scale + fade
2. Perfect: при perfect нота должна увеличиваться (scale 1.08)
3. Fail: при промахе должен быть красный flash + shake
4. Combo: при комбо должен быть glow эффект

### Проверка визуального дизайна:
1. Линии нотного стана должны иметь мягкие цвета
2. Ноты должны иметь тень
3. HUD должен отображать score, life, time, combo
4. Game over экран должен показывать рекорд и near-miss сообщение

## 📝 Примечания

- Система использует `requestAnimationFrame` с deltaTime
- Скорость в px/sec, вычисляется через travelTime
- Все конфиги вынесены в отдельные файлы для легкой настройки
- Daily challenge использует localStorage (без сервера)
- Near-miss работает только если есть сохраненный рекорд
